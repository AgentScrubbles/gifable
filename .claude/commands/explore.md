This codebase contains code for an interesting project, a self-hosted Gif server. It gives the ability for the server owner to upload gifs and serve them. Gifs can be embedded in other sites, be used in clients. This project also supports the full Matrix spec which allows images to be used in Matrix servers. Read through the application, documentation, and code to view the patterns, data structures, and DB migrations (for all supported DB providers).
